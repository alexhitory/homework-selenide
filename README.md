# Домашняя работа № 3 — UI-автотесты

Четыре независимых UI-теста учебного магазина [SauceDemo](https://www.saucedemo.com/).
Стек: Java 17+, Maven, Selenide 7.19.0, JUnit 5.11.4, паттерн Page Object.
Для запуска необходимы установленный Google Chrome и доступ к интернету.

## Сценарии

| Метод с `@Test` | Проверка |
| --- | --- |
| `successfulLogin` | Успешный вход, открытие каталога, наличие шести товаров |
| `invalidPassword` | Текст ошибки при неверном пароле |
| `addProductToCart` | Счётчик корзины, название, цена и количество добавленного товара |
| `removeProductFromCart` | После удаления товара корзина пуста, счётчик исчезает |

Учётные данные `standard_user` / `secret_sauce` опубликованы самим учебным приложением.
Перед каждым тестом открывается новая браузерная сессия; после теста браузер закрывается.
Тесты не зависят от порядка выполнения.

## Структура и инкапсуляция

```text
src/test/java/ru/homework/
├── pages/
│   ├── LoginPage.java       — форма входа и сообщения об ошибках
│   ├── InventoryPage.java   — каталог и переход в корзину
│   └── CartPage.java        — содержимое корзины и удаление товара
└── tests/
    ├── BaseUiTest.java      — настройки, создание и закрытие браузерной сессии
    └── ShopTest.java        — четыре сценария с @Test и @DisplayName
```

## Отчёты

Результаты JUnit: `target/surefire-reports/`.
При падении проверки Selenide сохраняет скриншот и HTML страницы в `target/selenide-reports/`.
